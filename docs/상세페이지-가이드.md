# 상세페이지 제작 가이드 (디자인 · 내용 구성 · 구조)

앞으로 상세페이지(랜딩페이지)를 만들 때 이 문서를 기준으로 합니다.
출처: 마케팅 강의 메모(랜딩페이지 19~22주차·33주차, 설득구조, 고정댓글), AI 이미지 → 상세페이지 제작 영상 대본(아트리스트 + 클로드 하이쿠 워크플로).

> 한 줄 원칙: **상세페이지는 "그거 왜 샀어?"에 대한 답이다.**
> 고객의 문제 → 그 문제의 답이 되는 내 상품 → 해결할 수 있다는 증거 → 가격보다 먼저 가치 → 망설임 제거 → 행동.

---

## 1. 만들기 전에 반드시 정리할 입력값 (INPUT)

상세페이지 카피는 아래 값을 먼저 채운 뒤에 씁니다. 비어 있으면 카피가 흔들립니다.

| 항목 | 내용 | 예시 (운동화) |
|---|---|---|
| ProductName | 상품·서비스 이름 | 데일리 쿠션 스니커즈 |
| Problem | 고객이 겪는 문제 (희망 + 걱정) | 오후면 발이 아프다 / 쿠션이 금방 꺼진다 |
| Features | 기능·특징·장점 | 3겹 쿠션, 280g, 슬립온 |
| Target | 타깃 구체 묘사 (생김새·하루 일과까지) | 하루 종일 서 있는 직장인 |
| Benefits | 고객이 얻는 핵심 결과 1~2개 | 퇴근길에도 발이 가볍다 |
| Price | 가격·결제 조건 | 정가 89,000 → 69,000원 |
| Guarantee | 보증·환불 조건 | 30일 착화 보증 |
| ProofData | 숫자·후기·성과 1~2개 | 평점 4.9, 누적 12,000켤레 |
| AltOptions | 고객이 흔히 시도하는 대안 A, B, C | 깔창 / 러닝화 / 캔버스화 |
| AltLimits | 각 대안의 한계 | 사이즈 애매 / 안 어울림 / 밑창 얇음 |
| TimeCost | 구매 후 필요한 시간·노력 | 1분, 3단계 |
| Story | 만든 사람·권위 한 줄 | 10년 신발 제작팀 |
| Scarcity | 한정 수량·기간·보너스 + **명분** | 2차 생산분 500켤레, 원단 수급 문제 |
| CTA | 버튼 문구 | 지금 구매하기 |
| OnePoint | 다른 곳엔 없는 **한끗 디테일** | 끈 없이 1초 착용인데 안 벗겨짐 |
| FAQ 재료 | 경쟁 상품 1점 후기·구매 전 망설임 | 발볼, 벗겨짐, 오염 |

**문제(Problem) 찾는 법**
1. AI에게 "이 상품을 찾는 사람들의 문제 7가지" 물어보기
2. 그중 내 상품이 해결하는 것만 남기고, 리뷰(쿠팡·네이버)에서 **실제 사례**를 찾아 전환 요소로 사용
3. 네이버 카페·커뮤니티·경쟁 상품 1점 후기에서 고객이 **실제로 쓰는 단어와 상황**을 수집
4. 문제는 "내가 만든 생각"이 아니라 **고객 머릿속에 이미 있는 욕구의 확장**이어야 한다

**잠재고객 상태 체크**
- 제품도 알고 욕구도 있다 → 제품 설명으로 시작
- 제품은 모르지만 욕구는 있다 → **욕구(문제)로 시작** (대부분 여기)
- 둘 다 모른다 → 상세페이지가 아니라 콘텐츠(풀링)로 먼저 욕구를 끌어내야 함

## 2. 기본 구조 — 15블록 설득 흐름

템플릿(`detail-page/assets/detail-page.js`)이 이 순서대로 렌더링합니다.
강의의 **랜딩페이지 기본구조**(문제 → 잘못 해결 시 결과 → 해결 → 한계 → 정답)와
**8블록 카피 템플릿**(헤드라인 → 문제 → 공감 → 대안 비교 → 솔루션 → 신뢰 → 오퍼·보증 → CTA)을 합친 구조입니다.

| # | 블록 | 역할 | 카피 공식 |
|---|---|---|---|
| ① | **히어로 (첫 화면)** | 0.5초 안에 "내 얘기다" | `{타깃}이라면` 호명 + `{문제 해결한 꿈의 상황}` 헤드라인 + 증거 배지 |
| ② | **증거 숫자** | 해결할 수 있다는 근거를 **맨 앞**에 | 평점 · 판매량 · 성과 수치 3개 |
| ③ | **문제 공감** | 현상 → 욕구 자극 | "혹시 이런 고민 있으세요?" + 고객 실제 표현 체크리스트 + 원인 한 줄 |
| ④ | **잘못 해결하면** | 손해·걱정 강화 | 사례 1, 사례 2 (구체적인 손해) |
| ⑤ | **대안과 한계** | 다른 선택지를 미리 정리 | "많은 분이 A, B, C를 시도하지만 ~한 한계가 있습니다" |
| ⑥ | **솔루션 + USP + 한끗** | 그래서 탄생한 답 | "그래서 만들었습니다 『상품명』" ✔ USP ✔ Features → Benefits + **원포인트 디테일** |
| ⑦ | **기능·특징 상세** | 일반적 특징까지 전부 | POINT 01~0N: 제목 + 설명 + 키워드 칩 + 이미지 |
| ⑧ | **비교표** | 일반 제품 vs 우리 | 항목별로 수치·사실 비교 (타사 브랜드명 언급 금지) |
| ⑨ | **후기 + 많이 팔리는 현상** | 사회적 증거 | 평점 요약 + 후기 카드(직업·사이즈 등 맥락) + 품절/배송지연 사과문 |
| ⑩ | **신뢰 (스토리·권위)** | 왜 믿어도 되는지 | 만든 사람·기간·인증·협업·특허 |
| ⑪ | **사용법·시간 비용** | "나도 할 수 있다" | `{TimeCost}` + 3단계 |
| ⑫ | **가치 → 가격 → 희소성** | 싸다고 느끼게 | 받는 것 목록(가치 총합) → 정가 취소선 → 할인가 → 하루 환산 → 한정 + 명분 |
| ⑬ | **보증** | 위험 0 | 조건부 환불: "A 동안 B 못 하면 C 해 드립니다" |
| ⑭ | **FAQ** | 구매 직전 망설임 제거 | 경쟁 상품 1점 후기 → 내 상품이 어떻게 해결하는지 |
| ⑮ | **최종 CTA** | 행동 | 결과 약속 헤드라인 + 버튼 + 마감 리마인드 |
| + | **하단 고정 CTA + 구매 체험** | 어디서든 바로 행동 | 가격 + 버튼 → 옵션 선택 → 주문 확인 → 완료 |

### 반드시 지킬 규칙 (강의 핵심)
1. **증거·증명·가치 시각화는 반드시 맨 앞에** (②). 숫자가 없으면 후기·인증·비포애프터로 대체.
2. **가격을 보여주기 전에 반드시 가치를 먼저 보여준다** (⑫). "단돈 ○○원"으로 느껴지게. 구성별 가치를 적고 총합을 취소선으로.
3. **상세페이지를 줄이려 하지 말 것.** 사려는 사람은 다 읽는다. 당연한 일반적 특징(청소기의 살균 브러시처럼)도 안 쓰면 경쟁에서 진다.
4. **한끗(원포인트) 디테일**을 하나 확실히 꽂는다. 메인이 아니어도 "이것 때문에 다른 걸 못 산다"는 포인트.
5. 상세페이지에 **다른 제품(대체재)은 넣지 않는다.** 보완재만.
6. 희소성·긴박감에는 **명분**이 있어야 한다. ("원단 수급 문제로", "트레이너 1인 20명 제한", "여러분의 관심이 많아서 할인가로 가져왔습니다")
7. 카운트다운·남은 수량은 **실제 값**만. 특가 종료 후엔 줄을 긋고 히스토리를 남겨 진짜임을 보여준다.
8. 썸네일(광고) → 콘텐츠 도입부 → 고정댓글 → 상세페이지가 **같은 문제**를 다뤄야 한다. 광고에서 말한 문제를 첫 화면에서 그대로 받아준다.
9. 클릭을 강요하지 말고 **무엇을 얻는지**에 집중한다.
10. 후기가 없으면: 체험단(후기 조건 무료 제공), 후기 작성 시 페이백, 지인 후기, 또는 경쟁 상품 1점 후기를 FAQ로 해소.

### 설득 요소 체크 (랜딩페이지 3포인트)
- **왜 내 상품이어야 하는가?** 논리(기술·가격) / 감정(스토리·타깃의 감정 묘사) / 자격(협업·기간)
- **3요소 설득 방법**
  - 후기: "많이 팔리고 있어요" → 품절·배송지연 사과문으로 표현
  - 증거: 비포/애프터, 1위·수상·인증·특허·시험성적서, 기능 GIF
  - 한정: 수량 제한(사전신청 → 본신청), 기회 제한(비밀특가·광고전용특가), 시간 제한
- **권위 형성**: 대형 브랜드 납품, 공공기관 인증, 전문가 인정, 국내 제조
- **나만의 특별함**: 고객 맞춤 문제 해결 / 불만 해결 / 궁금증(FAQ) 해결
- **가격의 당위성**: 구성별 가치 입증, 경쟁 제품 대비(1년 기준 vs 한 달 기준, 하루 환산)
- **"모두가 좋다는 것 → 아쉬운 점 → 그걸 보완한 제품"** 흐름도 히어로/솔루션에 활용 가능

### 상품이 여러 개일 때 (예: 리포트 / 전화 30분 / 전화 1시간)
- ⑫에서 **공통 가치 목록을 먼저** 보여주고, 그 아래 플랜 카드를 나란히 둔다 (`offer.plans`).
- 입문용은 "부담 없이 시작", 주력 상품은 `featured`로 강조, 큰 상품은 "작은 것 2번보다 ○원 이득"처럼 **실제 계산된 이득**을 적는다.
- 근거 없는 가치 금액은 쓰지 말고 `worth`를 비워 "✓ 포함"으로 표시한다.
- 신청 체험에서는 상품부터 고르고, 상품별로 필요한 옵션만 보인다 (`when`).
- 예시: `detail-page/pages/king-yena-love.html`

### 전환을 끌어올리는 추가 장치 (렌더러 지원)
| 장치 | 심리 원리 | 설정 |
|---|---|---|
| 어두운 히어로 + 공감 장면 목업 | 0.5초 안에 "지금 내 상황"을 보여줌 (공감 이미지) | `hero.style: "dark"`, `hero.image.mock: "chat"` |
| 누르는 자가진단 체크리스트 | 스스로 체크하면 '남 얘기'가 '내 문제'가 됨 (자기 인식·일관성) | `problem.results: [{min, text}]`, `hotFrom` |
| 조사 데이터 카드 | 실제 숫자로 손실 회피 자극 (출처 필수) | `pain.stat: {num, label, source}` |
| 상담 전 → 후 비교 | 구매 후의 나를 미리 그려 줌 (미래 그려 주기) | `change: {before, after}` |
| 추천 / 비추천 | 맞지 않는 사람을 먼저 밝히면 신뢰가 올라감 | `fit: {yes, no}` |
| 높은 가격부터 플랜 배치 | 첫 가격이 기준점이 되어 이후 가격이 가볍게 느껴짐 (앵커링) | `offer.plans` 순서 |
| 후기 대표 문장 띠 | 후기에서 가장 많이 반복된 구매 이유를 첫 화면 가까이에 | `quote: {text, by}` |
| 고민 유형 탭 | 유형을 고르면 "답을 찾는 질문 3개 + 추천 상품" → 선택 고민 감소, 해당 상품이 선택된 채 신청 창 열림 | `types: {items: [{name, who, questions, plan, sel}]}` |
| 특별한 점 나열 | 다른 상품과 직접 비교하지 않고 우리 상품만의 가치를 번호 카드로 | `points: {items: [{icon, title, text, note}], closing}` |
| 가치·메시지 섹션 | 아픈 이야기 → 희망으로 넘어가는 감정 전환점 | `manifesto: {lines, highlight, closing}` |
| 취소·환불 및 이용 안내 | 페이지 맨 끝 작은 글씨. 환불 기준·면책·개인정보·사업자 정보(전자상거래 필수 표시) | `legal: {groups: [{h, items}], biz: [{k, v}]}` |
| 상담 스타일 카드 | 원하는 것이 다른 두 고객층(예: 공감 / 해결)을 둘 다 '나를 위한 상품'으로 느끼게 → 신청 시 스타일 선택 | `styles: {items: [{icon, tag, name, who, promise, sel, dark}]}` |
| 변화 원리 섹션 | "어떻게 바뀌는지" 과정을 보여주고 실제 후기로 증명 | `method: {steps, quote}` |
| 운영자 소개의 '지켜본 사람들' 칩 | 경험의 폭을 한눈에 → 권위 + 호기심 | `trust: {people: [], story2}` |
| 결과물 목업 이미지 | 사진이 없어도 서비스 결과물(리포트·문장·통화 요약·일정)을 눈으로 보여줌 | `image.mock: "rewrite" / "report" / "call" / "timeline"` |

- 색: **CTA 색은 한 가지만, 다른 요소에는 쓰지 않는다.** 버튼은 색의 종류보다 주변과의 대비·고립이 클릭을 만든다. 흰 글자 대비 4.5:1 이상.
- 서비스(상담·강의)는 스톡 사진보다 **고객이 겪는 장면·결과물 목업**이 공감도가 높다. 사람 사진은 실제 운영자 사진을 쓴다.
- 예시: `detail-page/pages/king-yena-love.html`

### 상담 서비스 벤치마킹 메모 (크몽 연애상담 리뷰·판매 상위 3개, 2026-11 확인)
문구는 가져오지 않고 원칙만 정리한다 (상위 판매자 중 안내문 무단 인용·변형을 금지한 곳이 있음).
- **검증 가능한 권위**가 1위의 핵심: 저서·방송·플랫폼 등급/수상, "검색하면 확인 가능".
- **고민 유형별로 '상담하면 답을 찾는 질문'**을 제시해 결과를 미리 상상하게 한다.
- **포지셔닝을 분명히**: "막연한 위로만 원하면 권하지 않음", "희망 고문·과한 부정 없음" → 오히려 신뢰.
- **패키지마다 "이런 분께"**: 첫 상담 추천 상품, 복잡한 고민(재회·결혼)용 상품을 명시.
- 리뷰에서 반복되는 구매 이유: 마음이 정리됨 / 상대 심리를 정확히 짚음 / 무조건 내 편이 아닌 객관성 / 현실적 / 늦은 밤 빠른 응답 / 처음인데 편함 / 재상담.
- 가격대: 20~40분 2.9만~4.9만 원, 30~80분 7.5만~19.9만 원(상위 전문가). 크몽 가이드 기준 일반적으로 1회 3만~10만 원.

### 보증 3가지 유형
- 무조건 환불 100%
- 조건부 환불: "A 동안 B를 달성 못 하면 C를 해 드립니다"
- 환불 불가: 명분을 담아 표현 (가치가 있다는 신호)

## 3. 카피 작성법

### 헤드라인·문구 강화 5가지
1. **단어 강화**: 돈 버는 방법 → 돈 버는 치트키
2. **수치 강화**: 편해지는 꿀팁 → 200% 편해지는 꿀팁 3가지
3. **표현 강화**: 고객이 실생활에서 쓰는 표현으로 ("발바닥이 화끈거린다")
4. **문장 단순화**: 초등학교 3학년도 이해할 만큼 짧게
5. **타깃 최적화**: "30대 직장인이라면", "하루 종일 서 있는 분이라면" 처럼 직접 호명

### 벤치마킹 방법
- 같은 카테고리 1등 상세페이지(네이버·쿠팡·와디즈 베스트 펀딩) → **표현·설득구조** 수집
- 다른 카테고리 상세페이지 → **기본구조(배치)** 참고
- 참고 기준: 생성 후 3~6개월 이내, 신생 브랜드·퍼포먼스 광고 유입 페이지 / 유명인 기반·대충 만든 페이지는 제외
- **주제와 구조를 분리**해서 구조만 가져온다. 둘 다 가져오면 표절.
- "잘 팔리는 구조에는 있는데 내 구조에는 없는 것"을 찾아 추가한다.

### AI로 카피 뽑는 프롬프트
```
너는 전환 최적화 랜딩페이지 카피라이터야.
아래 〈INPUT〉을 읽고, 15블록 구조(①히어로 ~ ⑮최종 CTA) 제목을 그대로 사용해
직접 판매용 상세페이지 카피를 한국어로 작성해 줘.
{{중괄호}}는 모두 실제 내용으로 치환하고, 고객이 실제로 쓰는 표현을 사용해.

〈INPUT〉
ProductName: {{}}
Problem: {{희망 / 걱정}}
Features: {{}}
Target / Benefits / Price / Guarantee / ProofData / AltOptions / AltLimits /
TimeCost / Story / Scarcity(+명분) / CTA / OnePoint / FAQ 재료(경쟁 상품 1점 후기)

```
- 일반 특징 점검: "'{{상품}}'이라면 필수로 갖고 있어야 하는 일반적인 특징·기능이 뭐야?" → 내 페이지에 빠진 것 추가
- 망설임 해소: "내 상품을 사기 전에 사람들이 아래 내용 때문에 망설여. 내 상품의 기능·장점·특징을 바탕으로 해소하는 답변을 써 줘" → FAQ

## 5. 이미지 제작 워크플로 (AI, 영상 대본 기반)

**도구**: 클로드 + 아트리스트(Artlist) 커넥터 → 나노바나나 / GPT 이미지 / Flux / Seedream 등 사용 가능.
반복 수정이 많은 이미지 작업은 **빠르고 크레딧이 적게 드는 하이쿠** 모델이 편하다.

**순서**
1. 설정 → 커넥터 → 커스텀 커넥터 추가 → 아트리스트 MCP URL 붙여넣기 (최초 1회). 채팅창 `+` → 커넥터에서 **파란색(사용)** 확인
2. "참조 이미지를 입력할 수 있는 모델 확인해 줘. **아직 생성하지 말고 체크만**" → 크레딧 절약 (확인은 클로드 크레딧, 생성할 때만 아트리스트 크레딧)
3. 실물 사진 1장 업로드 (대충 찍어도 됨). 직접 업로드가 안 되면 "업로드 위젯 열어 줘"
4. 모델·비율·해상도까지 **디테일하게** 지시해서 대표 사진 1장 먼저 생성
5. 같은 제품으로 나머지 컷 생성 → 마음에 안 들면 **"○○는 유지하고 ○○만 바꿔 줘"**
6. "지금까지 만든 이미지 표로 정리해 줘" → 다운로드 (아트리스트 라이브러리에도 저장됨)
7. 이미지로 상세페이지 시안 → 빠진 이미지는 "기존에 만든 이미지 넣어 줘"로 수정 → 구매 과정 체험 버튼까지

**상세페이지용 이미지 세트 (블록별)**

| 블록 | 컷 | 비율 | 프롬프트 뼈대 |
|---|---|---|---|
| ① 히어로 | 제품 대표 사진 | 1:1 또는 4:5, 2K | 업로드한 제품 참조, 아이보리 스튜디오 배경, 부드러운 그라데이션 조명(단색 배경은 촌스러움), 45도 |
| ⑦ 기능 | 착용·사용 사진 | 4:5 | 같은 제품, 실제 사용 장면(야외·출근룩·일상), 자연광 |
| ⑦ 기능 | 디테일 사진 | 1:1 | 소재·마감·핵심 부품 매크로 클로즈업 |
| ⑥ 한끗 | 원포인트 디테일 | 4:3 | 한끗 기능이 보이는 손 클로즈업 또는 GIF |
| 광고/상단 배너 | 배너 | 16:9 | **왼쪽에 문구 넣을 여백** 비워 두기 → 이후 한글 제목·문구 합성 |
| SNS·썸네일 | 인스타 피드 | 4:5 | 같은 컨셉, 미니멀 / 도시적 / 일상 / 따뜻한 무드 변형 |
