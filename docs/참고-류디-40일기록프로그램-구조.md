## 3. 재사용할 핵심 패턴 10가지

1. **결과물을 맨 앞에 "만져지게"** — 과정보다 *끝에 받는 것*(리포트·편지·한 문장)을 먼저 보여주고, 실제 예시를 눌러 열어보게 한다.
2. **영상 + 타임스탬프 목차** — 긴 소개 영상을 목차로 쪼개서 원하는 부분만 보게 한다. 판매자 얼굴로 신뢰를 먼저 만든다.
3. **"다른 사람들이 얻은 결과" 모음** — 개별 후기보다 *결과물 자체*(한 문장들)를 나열해 기대치를 구체화한다.
4. **함께 + 혼자 두 갈래 구조** — 커뮤니티형(피드백·모임)과 셀프형(VOD·워크북)을 나눠 보여주고 그대로 가격 플랜으로 연결한다.
5. **문제 재정의(WHY)** — "방법을 몰라서가 아니라 ○○이 명확하지 않아서"처럼 근본 원인을 짚는다.
6. **시장의 방식/질문 vs 나의 방식/질문** — 대비 카드 2장으로 차별점을 한눈에 보여준다(남을 깎아내리지 않고 *관점 차이*로 표현).
7. **맞는 사람 ⭕ / 안 맞는 사람 ❌** — 대상이 아닌 사람을 명시해서 오히려 신뢰를 얻는다.
8. **"하지 않는 것"을 정직하게** — "편집·후킹은 가르치지 않아요"처럼 범위를 제한해 기대 불일치를 막는다.
9. **실행 걱정 해소 3포인트** — 진도 자유 / 방식 자유 / 판매자가 직접 읽음.
10. **심사형 신청서 + 하단 고정 버튼** — 바로 결제 대신 신청서로 진정성·희소성을 주고, 신청 버튼은 화면에 항상 떠 있다.

## 4. 디자인 메모

- 배경: 따뜻한 크림(#F6F3EE 근처), 카드: 흰색 + 아주 옅은 그림자 + 둥근 모서리(12~16px)
- 포인트: 코랄·주황 계열 1색만 — 테두리 박스, 형광펜 밑줄, 작은 라벨(영문 대문자 소제목: WHY RECORD, REAL VOICES, HOW IT WORKS)
- 글꼴: Pretendard 하나로 통일, 제목은 굵게·짧게, 본문은 회색 톤
- 이미지: 판매자 실제 화면 캡처(계정·매출·글 목록·카페 글)를 적극 사용 → 증명력
- 길이 관리: 스와이프 캐러셀(1/15), 접기/펼치기(상세 목차, 더 많은 후기), 좌우 스크롤 표
- 모바일 우선 단일 컬럼

## 5. 우리 상품에 적용할 때 (체크)

- [ ] 결과물(받아가는 것)을 구체적으로 정의할 수 있는가? 예시를 실물처럼 보여줄 수 있는가?
- [ ] 판매자 소개 영상(또는 음성)을 넣을 수 있는가? 없으면 사진 + 짧은 인사말로 대체
- [ ] 실제 고객의 결과물·후기가 있는가? 없으면 해당 섹션은 숨기거나 "예시" 표시 (지어내지 않기)
- [ ] 대상 ⭕ / 비대상 ❌ 을 정할 수 있는가?
- [ ] 마감·한정(기수, 얼리버드)이 **사실**인가? 사실일 때만 사용하고 명분을 함께 적기
- [ ] 신청서(심사형)가 맞는 상품인가, 바로 결제가 맞는 상품인가?

**어울리는 상품:** 기수제 온라인 프로그램, 코칭·컨설팅, 챌린지형 과정, 1:1 집중관리처럼 *기간이 있고 결과물이 남는 서비스*
(예: 킹예나 30일 1:1 집중관리 → "30일 후 받아가는 것: 관계 리포트" 구조로 응용 가능)
